# 西晋通婚谱系图

一个用来可视化魏晋之际（西晋皇室司马氏与其联姻士族）家族关系的交互式谱系图。纯前端、单文件输出，无需服务器。

![tech](https://img.shields.io/badge/html-vanilla-yellow) ![js](https://img.shields.io/badge/js-vanilla-yellow)

## 它能做什么

- 以**司马炎（晋武帝）**为中心，平铺展开他的嫔妃、子女，以及子女联姻对象背后的整个家族。
- 点选任意人物为焦点后，自动以该人物为中心重新布局。
- 左右拖拽平移、滚轮缩放、搜索姓名/字/谥号。
- 正妻子女从夫妻连线向下展开；妾室子女从妾室卡片向下展开。
- 点人物卡片旁的 `+N` 展开兄弟姐妹，点 `-` 收起；点婚姻连线收回配偶。
- 支持"全部折叠"弹簧开关、取消灰显、归并生母不详等视图控制。
- 家族配色：在配色表中登记过的家族按指定颜色填涂卡片，其余显示为灰白色。

## 目录结构

```
xi-jin-tong-hun/
├── export_data.py   # 读 Excel（.xlsm），转成 data.json（只有这个脚本碰 Excel）
├── data.json        # 纯数据：人物、婚姻、亲子、家族配色
├── core.js          # 布局引擎（只认识"人物/婚姻/亲子"抽象结构，不关心具体人名）
├── app.js           # 界面交互（拖拽、缩放、搜索、点击、折叠开关）
├── template.html    # 页面外壳（样式、按钮、弹窗）
├── build.py         # 把上面文件拼成一个 pedigree.html
└── pedigree.html    # build.py 生成的最终网页（双击即可打开）
```

## 快速开始

### 环境要求

- Python 3.8+
- `openpyxl`（仅在需要从 Excel 重新导出数据时需要）

```bash
pip install openpyxl
```

### 从源码运行

```bash
# 1. 如果改了 Excel 数据表，重新导出 data.json
python export_data.py "你的数据表.xlsm"

# 2. 把各模块拼成单文件网页
python build.py
```

生成 `pedigree.html`，用浏览器直接打开即可。

> 如果不带参数运行 `export_data.py`，它会在当前目录找最新的 `.xlsm` 文件。

## 数据格式

数据由 `export_data.py` 从 Excel 的四张表导出：

| 工作表 | 内容 |
|--------|------|
| 人物表 | 姓名、性别、字/谥号、家族、生卒年、排行、备注 |
| 婚姻关系表 | 丈夫、妻子、婚姻类型（正妻/继室/妾室） |
| 亲子关系表 | 父亲、母亲、子女、过继关系 |
| 旁系关系表 | 伯叔姑舅姨等旁系 |

如果你想把这套工具用到**别的历史家族**上，只需替换 Excel 数据后重新跑 `export_data.py` 和 `build.py`——`core.js` 和 `app.js` 不写死任何具体人名。

## 自定义配色

在 Excel 的"家族与配色表"中登记家族名和颜色（背景色、字色），导出后自动生效。未登记的家族显示为灰白色卡片。

## 技术说明

- 无任何框架、无构建依赖、无网络请求。
- `core.js` 是纯布局引擎，输入人物/婚姻/亲子数组，输出卡片坐标与连线坐标。
- `app.js` 负责把布局结果画成 SVG，以及所有鼠标/键盘交互。
- `build.py` 只是文本拼接，把数据和脚本内联进 HTML，方便分享和部署。

## 数据来源

人物关系依据《晋书》《三国志》《世说新语》（含刘孝标注）等正史与古注整理。
